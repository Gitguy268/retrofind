Retrofind

Private web search on your own Mac, in the style of 1998.

What it is

Retrofind runs SearXNG, a metasearch engine, on your own computer, without Docker. On top sits a start page and results page modelled on Google in 1998, in a Windows 98 window whose frame, title bar and taskbar are made of liquid glass.

Your searches go from your browser to your Mac, then on to several search engines at once. No single search company sees all of them, and nothing is stored.

Install

You need macOS and Homebrew.

brew install uv
git clone https://github.com/Gitguy268/retrofind.git

Then double-click start.command in the retrofind folder. The first run takes a few minutes, and then it opens http://127.0.0.1:8898/.

Search runs only on your computer, so there is no search box on this website.
